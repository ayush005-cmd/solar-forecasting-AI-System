# ☀️ Solar Power Generation Forecasting System

## 📌 Overview

This project is a **Machine Learning-based Solar Power Prediction System** that forecasts solar energy generation using historical and environmental data.
It helps in improving energy planning and efficient utilization of solar resources.

---

## 🚀 Features

* 📊 Predicts solar power output using ML models
* 🤖 Multiple models used (Linear Regression, Random Forest, etc.)
* 📁 Clean dataset preprocessing and feature engineering
* 🌐 Web interface using Flask
* 📈 Visualization of results

---

## 🛠️ Tech Stack

* Python 🐍
* Flask 🌐
* Scikit-learn 🤖
* Pandas & NumPy 📊
* HTML, CSS, JavaScript 🎨

---

## 📂 Project Structure

```
SOLAR/

│── requirements.txt      # Dependencies
│── static/               # CSS, JS files

│── model/ (ignored)      # Trained models (not uploaded)
```
